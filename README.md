# Bakalářská práce – C# aplikace pro práci s obrazovými a textovými daty

## Popis
Tato aplikace vznikla jako součást bakalářské práce na Technické univerzitě v Liberci.

Umožňuje:
- práci s obrazovými daty,
- práci s textovými daty,
- propojení s databází ElasticSearch,
- vyhledávání a zpracování dat prostřednictvím grafického rozhraní.

## Použité technologie
- C#
- .NET
- ElasticSearch
